5 popup design directions

Each mockup positions the popup at top: 25vh (so the modal opens between the top edge and the page center, not dead-center). Same data set in every design — searching for credential dumping techniques.

— 01
Command palette
Cmd-K style. Single search input, live results below grouped by relevance, footer with keyboard shortcuts. Feels like Spotlight or VS Code's command bar — fast, keyboard-driven.
Keyboard-first Single column Compact
— 02
Tactic browser
Left rail with all 14 MITRE tactics + counts. Right pane shows techniques in the selected tactic. Browseable for users who don't know exact T-IDs but know the kill-chain phase they're after.
Browseable Tactic-grouped Discovery
— 03
Card grid
Search bar + filter tabs (All / Trending / Recently added) above a 2-column grid of technique cards. Each card shows T-ID, name, tactic, platforms, and atomic-test count. Visual and scannable.
Card grid Filter tabs Visual
— 04
Glass spotlight
No card chrome — just a floating frosted-glass search field with each result row floating below as its own glass capsule. Minimal, premium, Apple-Spotlight feel. Selected row gets an accent gradient.
Minimal Frosted Premium
— 05
Split preview
Two-pane: search + results list on the left, live YAML preview of the selected technique on the right (with tabs for each atomic test). User can scan the YAML before committing — reduces "load and undo" cycles.
Live preview Two-pane Confidence
